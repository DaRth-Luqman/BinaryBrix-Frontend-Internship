# BinaryBrix Frontend Internship Projects

A collection of frontend web applications completed during the BinaryBrix internship, featuring a multi-page examination prep clone, an analytics dashboard, and a responsive single-page site.

## Tech Stack
* HTML5
* CSS3 (Bootstrap, Custom Grid/Flexbox Layouts)
* JavaScript (jQuery, Chart.js)

## How to Run
Run a local HTTP server in this directory or any of the subproject directories, and open the HTML files in a web browser. 

Example:
```bash
python -m http.server 8000
```
Then navigate to http://localhost:8000 in your browser.
